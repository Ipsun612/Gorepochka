О себе для Горепочки

0 / 2000

По умолчанию здесь пусто. Имя и @username из Telegram и сохранённая биография используются Горепочкой в следующих сообщениях во всех ваших диалогах и передаются ИИ-провайдеру через OpenRouter. Фото не передаётся. Не указывайте секреты и чувствительные данные.

Характер

15 черт

Выберите уровень каждой черты. Изменения действуют только для вас — во всех пяти диалогах, начиная со следующего ответа.

Настраивается только манера общения. Имя, возраст, интересы и правила безопасности не меняются. Даже сдержанная Горепочка остаётся уважительной и поддержит в тяжёлой ситуации.

Настройки передаются ИИ-провайдеру через OpenRouter. Сохранение не переписывает прошлые сообщения; уже начатый ответ использует прежний характер.
